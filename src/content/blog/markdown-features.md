Just a quick reference post covering the Markdown features available to any post in this blog.

## Headings

Use `##` and `###` for section headings within a post.

## Emphasis

Text can be **bold**, _italic_, or `inline code`.

## Lists

1. Numbered lists
2. work as expected
3. and so do nested items:
   - like this
   - and this

## Code blocks

```js
function greet(name) {
	return `Hello, ${name}!`;
}
```

## Quotes

> A blockquote renders with a left border and muted text.
